AlSunnah provides complete Bengali translations and in-depth commentary for Hadith from alsunna.net using Google Gemini.

Key Features:
- Direct Hadith translation from alsunna.net links.
- Dynamic script-aware font rendering: Bornomala font for Bengali and Scheherazade font for Arabic.
- Fully formatted Markdown output styling narrator statements and commentary as blockquotes with explicit references.
- Private and on-device session storage with Google authentication.
